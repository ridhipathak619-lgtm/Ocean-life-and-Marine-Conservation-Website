
# 🌊 OceanLife - Marine Conservation Website

**Explore the Ocean. Protect Marine Life. Save Our Planet.**

OceanLife is a responsive website designed to spread awareness about marine life, ocean ecosystems, and the importance of ocean conservation.

## ✨ Features

- 🌊 Beautiful ocean-themed homepage
- 🐬 Marine life information and images
- 🪸 Ocean ecosystems section
- ♻️ Marine conservation tips
- 💙 Ocean Club registration form
- 🎨 Attractive colors and hover effects
- 📱 Responsive website design
- 🧭 Easy navigation
- ✅ Form validation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

    OceanLife/
    ├── index.html
    ├── style.css
    ├── script.js
    └── README.md

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Ensure all files are in the same folder.
4. Open `index.html` in your browser.
5. You can also use the Live Server extension.

## 🌍 Website Sections

### 🏠 Home
Introduces OceanLife and its mission.

### 🐠 Marine Life
Showcases fascinating marine animals and habitats.

### 🪸 Ecosystems
Explores coral reefs, mangroves, the open ocean, and the deep sea.

### ♻️ Conservation
Shares tips for reducing plastic waste and protecting marine life.

### 💙 Join the Ocean Club
Allows visitors to enter their name, age, and email address.

## 🎯 Project Objective

The objective of this project is to promote marine conservation awareness and encourage people to protect ocean ecosystems through responsible everyday actions.
